# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary visitors are technical recruiters, prospective collaborators, and teams evaluating Yafte for backend or full-stack work. They need to quickly understand his specialty, experience, work samples, and a clear way to make contact.

## Product Purpose

This is Yafte's personal professional portfolio. It presents his backend-development profile, prior experience, selected work, technical stack, CV, and public professional links in Spanish and English.

## Positioning

The portfolio communicates a backend-first engineering practice through an interactive terminal/editor metaphor rooted in Yafte's own Black Ember Neovim theme, rather than a generic personal-site presentation.

## Operating Context

Visitors browse a single static page on desktop or mobile, switch between Spanish and English, follow links to live demos and professional profiles, download the CV, and use terminal-like navigation or ordinary links to move through sections.

## Capabilities and Constraints

- Static HTML, CSS, and JavaScript site hosted at `redyaafte.github.io`.
- Spanish and English are first-class interface languages, with the selected language persisted locally.
- Existing public links: GitHub (`RedYaafte`), LinkedIn, CV PDF, Reliability Insights Lab, TakoLab, and Órbita Matemática.
- Content claims are limited to repository evidence and the supplied public demos. The email shown in the existing site is a placeholder and must not be represented as verified.

## Brand Commitments

- Name: Yafte / `yafte.dev`.
- The user explicitly requests a terminal / Neovim character and the canonical Black Ember palette from the adjacent repository.
- Voice: direct, technical, bilingual, and professional.

## Evidence on Hand

- Existing portfolio copy and CV at `assets/cv/Yafte-CV.pdf`.
- Reliability Insights Lab README and source at `/home/yafte/dev/improve-portfolio`, linked to its public GitHub repository.
- Black Ember palette at `/home/yafte/dev/black-ember/palette/black-ember.toml`.
- Public demos: TakoLab describes itself as software that adapts to a business; Órbita Matemática offers visual lessons, practice, and progress tracking for secondary-school mathematics.
- Existing professional history and technologies in `index.html`.

## Product Principles

- Make relevant professional proof reachable in one or two actions.
- Let the interface demonstrate engineering personality without hiding standard web affordances.
- Respect visitors' language choice and keyboard use.
- Prefer precise, evidence-backed copy over inflated claims.
